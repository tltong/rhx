Default article length

Word targets guide the total story text across the article. One rewrite may improve the length; a count difference does not block preparation. Grades inherit these values unless an override is entered.

Images by article type

Grades using the same type share its image settings. Web photos are tried twice, then the complete image set falls back to labelled AI illustrations. An article uses one image type throughout.

Grade settings

Choose one format per grade. Blank word and page fields inherit defaults. A picture-story word target of zero means pictures only; its image count determines its page count. Standard articles have one page. Vocabulary counts cover distinct words or short phrases across the article; zero disables highlights. Each article has three comprehension questions. Choose typed answers or a shared word bank for each grade.

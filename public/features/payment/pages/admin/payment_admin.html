Renewal retries and access suspension

Configure the retry count, retry interval and suspension grace period separately. The grace period starts at the first failed renewal payment. Access stays active until grace ends, even if all automatic retries finish earlier. Only retries scheduled within grace run automatically. A retry due exactly at the grace deadline is skipped. Successful payment starts a full new billing period. Changes apply to newly failed renewals.
